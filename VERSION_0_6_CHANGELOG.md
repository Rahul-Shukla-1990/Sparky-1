# v0.6 Changelog

## Added

- Explicit source attribution fields on incident records.
- Source provenance block on incident cards.
- Telegram submitter display on dashboard.
- Telegram group and message ID visibility.
- Manual dashboard submitter display.
- Provenance fields in CSV/JSON exports.
- Provenance fields in daily markdown briefs.
- Source attribution documentation.

## Why

Each input must show where it came from and who shared it. This is particularly important for Telegram group intake where multiple collectors may contribute leads.
