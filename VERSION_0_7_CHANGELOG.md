# v0.7 Changelog

## Added

- Per-incident mini-map panel.
- Incident cluster model and cluster membership model.
- Cluster creation tab in dashboard.
- Add incident to cluster from each incident card.
- Daily / Weekly / Monthly / Half-Yearly / Annual report inclusion flags.
- Report graphs by reporting period.
- Cluster-wise, category-wise and alert-level graph data.
- Local image/document upload support.
- Link attachment support.
- Attachment list per incident.
- Static serving of uploaded files from local data/uploads.
- Livelier dashboard styling with visual emphasis and animated background.
