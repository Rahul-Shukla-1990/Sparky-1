# v0.5 Changelog

## Added

- Public API Catalogue Manager.
- Live/fallback catalogue import.
- Parser for public-apis README markdown tables.
- Maritime relevance scoring for API candidates.
- API candidate database table.
- API candidate dashboard tab.
- Admin approval/rejection workflow.
- Approved candidates become disabled source templates.
- Audit logging for catalogue import and candidate approval/rejection.
- Documentation for API catalogue usage.

## Design Decision

The public-apis repository is used only as a discovery catalogue. It is not treated as a verified maritime source and nothing is activated automatically.
