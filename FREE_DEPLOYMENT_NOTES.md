# Free Deployment Notes

## Strictly Free Option

Run the system on:
- Own computer
- Spare laptop
- Office workstation
- Local server
- Raspberry Pi-class device, if performance is acceptable

Advantages:
- No cloud billing
- No mandatory paid API
- Full local control
- Easy to shut down, isolate or back up

Limitations:
- Runs only while machine is powered and online
- Public remote access requires network configuration

## Cloud-Free-Tier Option

Cloud free tiers can be explored later. They must not be assumed to be permanently free because billing, region restrictions, storage, egress and quota limits can create charges.

## Recommended No-Cost Operational Model

1. Run locally first.
2. Keep SQLite initially.
3. Keep source count moderate.
4. Use GDELT, RSS, public official pages, and manually approved URLs.
5. Add cloud only after cost guardrails are defined.
