# Sparky Maritime Intelligence Platform

This repository provides a working foundation for a maritime intelligence platform inspired by Windward AI and MarineTraffic/VesselFinder. The system focuses on detecting dark vessel activity, AIS spoofing, and delivering interactive map-ready analytics for the Indian Ocean Region with global scalability.

## Features

* FastAPI backend capable of ingesting AIS messages from MongoDB and public community feeds.
* Dark-activity detection that validates water-only routes and flags infeasible travel during AIS blackouts.
* Identity-change tracking across multi-decade histories to surface MMSI/IMO spoofing behaviour.
* Daily analysis endpoints for the Indian Ocean Region with scope to scale to additional theatres.
* Map overlays for global Exclusive Economic Zones (EEZ/IMBL), territorial seas, contiguous zones, internal waters, archipelagic waters, high seas references, and extended continental shelf claims alongside undersea infrastructure and chokepoints.
* Operator-facing tools for uploading custom GeoJSON layers with on-map styling controls (colour pickers, line widths, opacity sliders) and rapid visibility toggles.
* Automated tests covering detection services and HTTP endpoints.

## Getting started

1. Install [Poetry](https://python-poetry.org/) if it is not already available.
2. Install dependencies and run the development server:

   ```bash
   poetry install
   poetry run uvicorn app.main:app --reload --app-dir backend
   ```

3. Execute the automated tests:

   ```bash
   poetry run pytest
   ```

Environment variables prefixed with `SPARKY_` (see `backend/app/config.py`) control database connectivity, history depth, and other runtime configuration.

## Running the offline demo server

In restricted environments where installing dependencies from PyPI is not possible, you can still exercise the project by
launching the bundled offline HTTP server. The server returns synthetic AIS tracks for 50 vessels, identity-change events, dark
activity detections, and bilingual map layers so you can explore the full data workflow.

```bash
python -m backend.app.demo_server
```

Once the server is running, open a new terminal and query the sample endpoints:

```bash
curl http://localhost:8000/health
curl http://localhost:8000/vessels/500000000
curl http://localhost:8000/vessels/500000000/dark-activity
curl http://localhost:8000/layers/undersea-cables
```

These responses mirror the FastAPI payloads and can be visualised on an interactive map or used to test client applications.

### Quick Python launcher

Prefer a single entry point? Run `python run_demo.py` (optionally with `--open` to launch your browser automatically). The helper simply wraps the offline server above, so no external dependencies are required.

### Viewing the interactive demo UI

With the demo server running, open a browser and navigate to <http://localhost:8000/> to launch the Windward-style console. The page is fully client-side (no extra tooling required) and showcases:

* A full-screen MapLibre MOD (Main Operations Display) with ocean-blue styling, radar sweep, and neon AIS markers.
* WebSocket-driven AIS drifts and SAR detection pulses updating every second for all 50 synthesised MMSI/IMO identities.
* A right-hand vessel tote with bilingual labels, live status badges, dark-activity metrics, and animated track playback highlights.
* A left AI assistant card for natural-language queries plus a bottom-left AOI drawer with drawing/export actions.
* Toggleable overlays for global EEZ/IMBL boundaries, legal maritime zones (territorial sea, contiguous zone, internal waters, archipelagic waters, high seas, extended continental shelf), undersea cables, shipping lanes/SLOCs, ports, AOI templates, an official India territorial outline, and an Indian Ocean risk heatmap.
* A custom intelligence layer palette for uploading GeoJSON overlays directly in the browser and tuning style (colour, line width, fill/opacity) without leaving the MOD.
* Integrated events tray surfacing AIS silence, SAR matches, and other alerts generated by the demo fusion loop.

If you change the Python dataset, simply refresh the browser to see the updated intelligence.
