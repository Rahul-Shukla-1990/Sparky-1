# Maritime OSINT Agent v0.4

## Free, Local-First Maritime Incident Monitoring

The Maritime OSINT Agent is a small-team platform for collecting, classifying and reviewing maritime incident information across the Indian Ocean Region and connected maritime approaches.

## Core Capabilities

- Automated open-source collection.
- Telegram group intake for multiple collectors.
- Manual social-media/link submission.
- Nine-category maritime incident taxonomy.
- Analyst review workflow.
- Incident deletion, reclassification and comment editing.
- Dashboard map, filters, export and daily briefs.
- Audit log for accountability.

## Designed For

- Maritime domain awareness teams.
- Fusion centres.
- Security analysts.
- Research cells.
- Small OSINT teams.

## No-Cost Operating Philosophy

The system is local-first and free by default. It avoids mandatory paid APIs, paid hosting, paid AI models and paid social-media access.

## Collection Categories

1. Piracy & Armed Robbery
2. Contraband Smuggling
3. IUU Fishing
4. Illegal Human Migration
5. Maritime Incidents
6. Maritime Security Threats
7. Maritime Environmental Pollution
8. Maritime Cyber Security
9. Hybrid Threats to Maritime Security

## Operational Value

The platform converts scattered public reporting and human-submitted leads into a structured incident queue, enabling faster triage, better source attribution and improved daily maritime situational awareness.
